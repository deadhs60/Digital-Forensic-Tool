# Digital-Forensic-Tool

Step1
  Download the zip file in your local workstation and extract it

Step2
  Open the Project in VS Code

Step3
  Open terminal in VS Code (Ctrl + Shift + `) and run below command
  pip install -r requirements.txt

Step4
  Open your browser, go to "https://exiftool.org/" and download ExifTool

Step5
  Extract downloaded zip file and rename exiftool(-k).exe with exiftool.exe

Step6
  Add the path of ExifTool in your System Variable (Environment Variable)

Step7
  Now come back in your VS Code window, and run the below command
  streamlit run app.py

Now, you can perform analysis on any file or any browser history by follow the on screen instruction.
